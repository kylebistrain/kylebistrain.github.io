NNs & No-Arbitrage Option Pricing

Developed a deep learning framework for American SPY option pricing that incorporates implied volatility features to improve out-of-sample RMSE by up to 70% compared to Black-Scholes-Merton.

  • Implemented a walk-forward framework with reproducible data cleaning, rolling cross-validation, and no-arbitrage diagnostics.

QUANTITATIVE Trading

I’m an options trader using an R Shiny dashboard to support bull and bear spread trading. The dashboard integrates the commercial NNS R package, which uses nonlinear, nonparametric diagnostics based on partial moments and stochastic dominance to compare payoff distributions. These outputs are combined with pricing and implied volatility data to assess regimes, relative risk, and assumption breakdowns.
